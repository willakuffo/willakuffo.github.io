# Academic website

## Publish on GitHub Pages
1. Create a public repo named `<your-username>.github.io`.
2. Upload `index.html` (plus `profile.jpg` and `cv.pdf`) to the repo root.
3. Settings → Pages → Source: "Deploy from a branch", branch `main`, folder `/ (root)`.
4. Live in ~1 minute at `https://<your-username>.github.io`.

## Customize
- **Photo:** add `profile.jpg` (square). Without it, initials show.
- **CV:** add `cv.pdf`.
- **Links:** uncomment the Scholar / GitHub lines in the sidebar and add URLs.
- **New publication:** copy a `<div class="pub">` block.
- **New project/role:** copy a `<div class="entry">` block.
